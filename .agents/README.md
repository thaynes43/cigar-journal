# Agent Docs

Rules and reference material for agents working in this repository. Product and
engineering documentation (PRDs, ADRs, domain flows) lives in [`docs/`](../docs/README.md).

- [`rules/`](rules/) — constraints and procedures agents must follow.
- [`reference/`](reference/) — factual context: formats, related systems, gotchas.

Conventions: branch per task (`agent/<task-slug>`), never push to `main`, open a
PR for every change.
