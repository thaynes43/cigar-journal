# Archive: Markdown Ledger

The original cigar journal — a Material for MkDocs site of hand-written tasting
notes, purchase history, and reference pages. It has been replaced by the
application at [cigars.haynesnetwork.com](https://cigars.haynesnetwork.com),
which imported all 36 reviews from these pages as its seed data.

The archive stays published at
[hayneslab.net/cigar-journal](https://hayneslab.net/cigar-journal/) as the
original record, and its build must keep working (AGENTS.md) until the owner
retires it. Every page carries a banner pointing readers at the new site
(`overrides/main.html`); the pages themselves are unchanged.

New entries are written in the application, not here. The content format is
documented in
[.agents/reference/archive-format.md](../.agents/reference/archive-format.md).
