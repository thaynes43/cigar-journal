# Archive: Markdown Ledger

The original cigar journal — a Material for MkDocs site of hand-written tasting
notes, purchase history, and reference pages. It remains published at
[hayneslab.net/cigar-journal](https://hayneslab.net/cigar-journal/) until the
new application replaces it, and its content will be imported as the journal's
seed data.

The content format is documented in
[.agents/reference/archive-format.md](../.agents/reference/archive-format.md).
Entries may still be added here until the import happens.
